# Amazon Store Sales Analysis

## Problem Statement  
This project aims to analyze Amazon store sales data and create an interactive dashboard using Power BI. The dashboard provides actionable insights into sales performance, trends, customer behavior, and regional segmentation to aid decision-making and optimize sales strategies.  

---

## Key Performance Indicators (KPIs)  
The following KPIs are tracked and analyzed in the project:  
- **Total Sales**  
- **Total Orders**  
- **Total Products Sold**  
- **Total Number of Customers**  
- **Sales by Year**  
- **Sales by Region**  
- **Sales by Segment**  
- **Top 10 Customers by Sales**  
- **Customer Sales and Purchase Details**  
- **Sales by City**  

---

## Steps Followed  

### 1. **Data Preparation and Cleaning**  
- Imported raw Amazon store sales data into Power BI.  
- Cleaned and transformed data using Power Query to ensure data quality and consistency.  

### 2. **Data Processing**  
- Created custom columns and measures using DAX functions to calculate key metrics such as total sales, total orders, and sales trends.  
- Generated additional insights like customer rankings, regional sales distribution, and sales segmentation.  

### 3. **Data Visualization**  
Built an interactive and visually appealing dashboard with the following components:  
- **KPIs**:  
  - Displayed **Total Sales (2.30M)**, **Total Orders (5009)**, **Total Products Sold (1862)**, and **Total Customers (793)** in summary cards.  
- **Yearly Trends**:  
  - Visualized **Sales by Year** using a line chart.  
  - Highlighted year-over-year growth trends.  
- **Regional and Segment Analysis**:  
  - Used pie charts to represent **Sales by Region** (West, East, Central, South) and **Sales by Segment** (Consumer, Corporate, Home Office).  
- **Top 10 Customers**:  
  - Listed top-performing customers by sales with their total sales, quantity, and orders using a table.  
- **City-Wise Sales Analysis**:  
  - Showcased sales distribution across cities with a tree map for detailed insights.  

---

## Features of the Dashboard  
- **Interactive Filters**:  
  - Year  
  - Region  
  - Segment  
  - Customer Categories  
- **Dynamic Visuals**:  
  - Charts and metrics dynamically update based on selected filters.  
- **Insights and Highlights**:  
  - Top customers and sales trends are easily identifiable.  
  - Regional and segment-wise breakdowns allow for detailed analysis.  
- **User-Friendly Design**:  
  - Intuitive layout with key metrics prominently displayed.  

---

## Tools and Technologies Used  
- **Power BI**: For data visualization and dashboard creation.  
- **Power Query**: For data cleaning and transformation.  
- **DAX (Data Analysis Expressions)**: For creating custom calculations and measures.  

---

## Final Output  
The final Power BI dashboard delivers comprehensive insights into Amazon store sales performance. It empowers stakeholders to:  
- Track performance metrics such as total sales, orders, and customers.  
- Analyze trends in sales by year, region, and customer segment.  
- Identify top-performing customers and regions.  
- Gain insights into customer purchase behavior.  
- Optimize business strategies using actionable data.
